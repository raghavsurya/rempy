# Project - Rempy
Python - FastAPI project exposing functionalities such as 
- User signup / signin / account management
- Create reminders
- Create household and link users
- Search reminders using AI
- Track credit cards, upcoming payments, trips and many more

## Dev environment tips
- use `uvr` for running the app. `uvr` is an alias for `alias uvr="uvicorn main:app --app-dir src --port 8077"`
